# Schweiz IPTV

Astro static website for `schweiz-IPTV.net`.

- German homepage: `/`
- French version: `/fr/`
- Build command: `pnpm build`
- Output directory: `dist`

The project includes localized SEO metadata, canonical URLs, hreflang alternates, robots.txt, sitemap, legal pages, offer cards, WhatsApp offer links, and responsive layout based on the original IPTV En Suisse design.
